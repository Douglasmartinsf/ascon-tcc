# Resultados

`simulation/` reúne resumos funcionais e manifestos. `synthesis/` registra elaboração, constraints e métricas disponíveis. `layout/` recebe resultados selecionados de implementação física.

Cada relatório identifica comandos, ferramenta, resultado e limites. Logs brutos e diretórios de execução são regeneráveis e ficam fora do versionamento. Manifestos datados descrevem os conteúdos históricos; documentação revisada não altera a evidência original.
